# Partline — поиск автозапчастей

Тестовое задание: двухэтапный поиск производителей, предложений и аналогов по артикулу.

**Стек:** React 18, Redux, JavaScript (без TypeScript), Bootstrap и CSS, Vite. Небольшой сервер на Node.js без дополнительных серверных зависимостей.

## Быстрый запуск

Требуется Node.js 20.14+ и npm.

```bash
npm ci
npm test
npm run build
npm start
```

Откройте **http://127.0.0.1:3001/**. Демо включено по умолчанию; регистрация и ключ API не нужны. Артикул `01089` уже подставлен. Цены и остатки в демо вымышлены, это обозначено в интерфейсе.

## Как проверить

1. Выберите `CAFFARO` или `ZEN`: появятся четыре складских предложения, включая аналоги.
2. Включите «Только в наличии»: останутся два предложения.
3. Выберите «Сначала дешевле»: минимальная цена окажется сверху.
4. Введите `EMPTY` или любой неизвестный артикул: появится пустой результат.
5. Введите `ERROR`: появится ошибка сервиса и кнопка повторного запроса.
6. Очистите артикул или измените его: старые бренды и предложения сбросятся.

## Реальный API

В задании не предоставлен действующий ключ клиента. Реальные ответы с ключом **не проверены**. Запрос без ключа из среды разработки получил HTTP 403.

Создайте `.env` на основе `.env.example`, задайте `VITE_DEMO=false` и `FAVORIT_API_KEY`, затем:

```bash
npm run build
node --env-file=.env server.mjs
```

Vite читает `VITE_DEMO` при сборке. Ключ читает только сервер; он не включается в клиентскую сборку. Не публикуйте `.env`. Для возврата к демо установите `VITE_DEMO=true` и пересоберите приложение.

[Документация API](https://lk.favorit-parts.ru/static/wsprice.pdf), версия от 06.03.2023. В PDF указан HTTP, но приложение обращается по HTTPS, чтобы не отправлять ключ открытым текстом. Доступность HTTPS с рабочим ключом необходимо подтвердить у поставщика. Автоматического перехода на HTTP нет.

## Поведение

- Ввод артикула запускает поиск через 500 мс после окончания ввода; кнопка запускает его сразу.
- Первый запрос передаёт `number`, второй — `number`, `brand`, `analogues=on`.
- Redux хранит артикул, выбранного производителя, результаты, загрузку и ошибки.
- Старые запросы отменяются; запоздалые ответы не заменяют актуальные результаты.
- Загрузка, пустой ответ, ошибка API, сетевой сбой и таймаут обрабатываются отдельно.
- Каждая строка таблицы соответствует предложению конкретного склада. Цена берётся из `warehouses.price`, остаток — из `warehouses.stock`. Устаревшее `goods.price` не используется, нулевые остатки сохраняются.
- Серверный прокси решает вопрос CORS и хранит ключ вне браузера.
- Адаптивная компоновка, горизонтальная прокрутка таблицы на узком экране, подписи полей и клавиатурный фокус.

## Разработка

Запустите `npm start`, затем в другом терминале `npm run dev`. Vite проксирует `/api` на `127.0.0.1:3001`. Для реального API вместо `npm start` используйте `node --env-file=.env server.mjs`.

## Структура

- `src.jsx` — интерфейс, запросы, отмена и debounce.
- `data.js` — преобразование API-ответов и Redux reducer.
- `server.mjs` — API-прокси, демоданные и раздача сборки.
- `style.css` — оформление и адаптивная компоновка.
- `test.mjs` — проверки ошибок, пустых ответов, брендов, аналогов, складских цен и сброса результатов.

`npm test` запускает встроенный тестовый раннер Node.js. `npm run build` создаёт production-сборку в `dist/`.
